### Key Findings
- **OCPBUGS-134744**: supported Private ↔ PublicAndPrivate transitions retain the private KAS endpoint; pure-Public cleanup is not a prerequisite for Day 1 deterministic LB IP, so the PR was closed Won't Do.
- **[#10208](https://github.com/openshift/hypershift/pull/10208)**: `sleep infinity` as PID 1 never reaps orphaned curl processes, so zombies pin seccomp BPF until memlock exhaustion; the fix uses a `wait` loop and was flagged for the 4s `--max-time` vs 5s probe timeout.
- **[release#88071](https://github.com/openshift/release/pull/88071)**: `pipeline_run_if_changed` misses configrefs/nodepool/globalconfig/HCCO paths, and the optional `registry-overrides` lane can go green with zero specs until the companion PR merges.
- **[aws-leaked-resources#1](https://github.com/hypershift-community/aws-leaked-resources/pull/1)**: orphan detection can delete IAM/OIDC of live clusters in other regions or shared/untagged VPCs; HeadObject and non-S3 OIDC errors collapse to LEAKED instead of UNCERTAIN.
- **[#9965](https://github.com/openshift/hypershift/pull/9965) / [release#87085](https://github.com/openshift/release/pull/87085)**: the Azure suite targets Velero 1.13, which the story excludes (OADP 1.5+ baseline); the release PR wires optional presubmits while the story requires periodics and adds no GCP coverage.
- **CNTRLPLANE-1163**: baseline is OADP 1.5+ with Velero following the selected OADP; the OCP→OADP→Velero matrix is TBD with the OADP team and user-workload validation awaits Lucas Ponce.
- **[#10186](https://github.com/openshift/hypershift/pull/10186)**: the `update-ci-job-registry` nightly has failed since the two `e2e-rosa-seaplane` jobs appeared; without a ROSA rule the generator exits before printing `release_sha`.
- **CNTRLPLANE-4797**: Day 1 deterministic LB IP documentation merged in [#10207](https://github.com/openshift/hypershift/pull/10207).
