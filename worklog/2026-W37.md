### Key Findings
- **CI-2/CI-3 NAT gateway incident**: Both NAT gateways deleted by `sminonne` at 2026-09-04T19:34:50Z (1s apart). Route tables left with blackhole `0.0.0.0/0`. Impact: 29 HCs across both clusters stuck with `ValidReleaseImage=False`. CloudTrail confirms manual CLI commands from same session.
- **ROSA DR integrity analysis**: CSI Volume Snapshots are crash-consistent, not application-consistent — but "not application-consistent" ≠ "not recoverable." EBS snapshots + etcd WAL CRC + bbolt two-phase commit = fully recoverable by design. Document overstates risk.
- **[#9514](https://github.com/openshift/hypershift/pull/9514)** (CNTRLPLANE-2007): KubeVirt ingress passthrough — day-2 strategy changes silently ignored (create-only IngressController). Missing tests for `NodePort != 0` guard and empty-type fallthrough.
- **[#9527](https://github.com/openshift/hypershift/pull/9527)** (HYPERFLEET-1557): Platform monitoring gate — version skew risk (new CPO defaults monitoring off). Author fixed with `AdditionalOperatorEnvVars` blocklist + integration test.
- **[#9506](https://github.com/openshift/hypershift/pull/9506)** (OCPBUGS-120685): `getDefaultNodePool` latent bug — 28+ callers vulnerable to race with deleting NPs. Author hardened directly with `DeletionTimestamp` + `Replicas` guards.
- **RITS [#9489](https://github.com/openshift/hypershift/pull/9489)**: 6 presubmit failures on release-5.0 — only 2 (compliance test) caused by missing kas-connection-checker annotation. Other 4: HO rollout flake, kubevirt infra, karpenter drift. Backport [#9534](https://github.com/openshift/hypershift/pull/9534) fixes compliance test.
- **CNTRLPLANE-1053**: Goroutine leak in `forwarder.go` — unbuffered `errChan` blocked goroutine forever on happy-path. Fixed with `make(chan error, 1)`.
