### Key Findings
- **[OCPSTRAT-2653](https://redhat.atlassian.net/browse/OCPSTRAT-2653) Day 2 analysis**: DNS Indirection has 3 critical issues — InPlace upgrade race (MCD overwrites `kas-hosts` with stale IP), scale-up still needs old IP alive, ignition update is circular. Transition Service: 5 CP components, zero data plane, 1-link chain. DNS: 7 components, 6-link chain.
- **[#9595](https://github.com/openshift/hypershift/pull/9595) ([OCPBUGS-122896](https://redhat.atlassian.net/browse/OCPBUGS-122896))**: `defer response.Body.Close()` inside infinite retry loop leaked HTTP response bodies in availability-prober init containers.
- **[#9507](https://github.com/openshift/hypershift/pull/9507) ([OCPBUGS-120802](https://redhat.atlassian.net/browse/OCPBUGS-120802))**: Hidden bug in `support/certs/tls.go:471` — `hasKeys` passes `CASignerKeyMapKey` twice instead of cert+key. PR's explicit guard is real defense.
- **[#9691](https://github.com/openshift/hypershift/pull/9691) ([OCPBUGS-126614](https://redhat.atlassian.net/browse/OCPBUGS-126614))**: `optionalOldSelf=true` silently reintroduced in `af4ad5e9`. `route: {}` now required when `type: Route` — breaking for ACM, ROSA, ARO.
- **MCS path exclusion**: Files not declared in any MachineConfig are invisible to MCD — HyperShift can manage `kas-hosts` via DaemonSet without MCD interference.
- **MCD `--exclude-paths` feasibility**: 6 change points across 5 MCO files + 1 HyperShift file. ~60-80 lines. Main risk: MCO team rejection.
- **[release#86393](https://github.com/openshift/release/pull/86393)**: 4.19 is the only release with active `e2e-aws-critical` cron and doesn't get `AWS_REGION_OVERWRITE: us-east-1` — most affected release missing the fix.
