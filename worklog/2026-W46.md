### Key Findings
- **[release#88798](https://github.com/openshift/release/pull/88798)** (OCPBUGS-140134): the new CNV convergence barrier fails open — failed `oc get` reads and the initial MCP probe are both treated as converged — so it can be bypassed during the management-node reboot it is meant to cover; it also needs an explicit step timeout.
- **[#9146](https://github.com/openshift/hypershift/pull/9146)** (CNTRLPLANE-4166): blocking result-ConfigMap RBAC (Kubernetes cannot scope `create` by `resourceNames`) and `e2e-v2-aws-backuprestore` fails on a GVK-missing `resolveBSL`; incomplete restores are not enforced at admission.
- **[#10036](https://github.com/openshift/hypershift/pull/10036)** (CNTRLPLANE-4639): `WorkerAvailable` is unreachable because `hcp.Status.KubeConfig` is set before workers join; `CheckRouteAdmission` can flap availability on unrelated routes; the e2e injection test taints shared CI nodes.
- **[#9693](https://github.com/openshift/hypershift/pull/9693)** (OCPBUGS-126616): the change cannot surface the failure it describes — `multiNamespaceCache.Start` only returns on `ctx.Done()`; the real failure surface is informer sync/`CacheSyncTimeout`.
- **[#9691](https://github.com/openshift/hypershift/pull/9691) / [#9692](https://github.com/openshift/hypershift/pull/9692)** (OCPBUGS-126614/126615): re-enabling CEL removes the `<4.17` cost-budget TODO without evidence and hard-fails existing clusters; the reserved-key list misses `control-plane`, which breaks the CAPI provider Deployment selector.
- **[enhancements#2178](https://github.com/openshift/enhancements/pull/2178)** (OCPSTRAT-1598): the Azure PLS-only fallback does not cover ARO (Swift skips the PLS controllers), and Case 3.7 uses standalone `api-int:22623` instead of the published HyperShift ignition endpoint (HTTPS/443).
- **[#10291](https://github.com/openshift/hypershift/pull/10291)** (OCPBUGS-140722): the Event TTL false negative is string-vs-duration equality; the fix gates propagation to 5.1+ and compares parsed `time.Duration`, but still needs merge and test-image promotion for 5.0/4.22.
- **CI Keeper (12 Nov)**: the main `e2e-aws`/`e2e-aks` blocker is empty `imageStreamImportMode` serialization ([openshift/api#3116](https://github.com/openshift/api/pull/3116)); also found an inverted MirrorConfigs deletion assertion, late NTO status production and worker Ignition EOF; the GKE 5.1 periodic drop was root-caused to CP restart races + etcd `standard-rwo` IOPS.
