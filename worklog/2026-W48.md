### Key Findings
- **[#10341](https://github.com/openshift/hypershift/pull/10341)** (CNTRLPLANE-4579): The AWS E2E lane now rejects missing EIP inputs and fails a selected spec that would previously skip; live execution of the lane is still unverified.

- **[hypershift-oadp-plugin#339](https://github.com/openshift/hypershift-oadp-plugin/pull/339)** (OCPBUGS-135292): The plugin now accepts only snapshots that belong to the selected backup and strips inherited restore URLs from PVC restores.
- **Azure public exposure audit:** All 14 flagged public IPs were already deleted; the report reflected a stale snapshot, not live exposure.
- **[#10245](https://github.com/openshift/hypershift/pull/10245)** (CNTRLPLANE-4822): Legacy failure-domain data can break typed reads after the CRD upgrade, and existing provider images can write conditions the new schema rejects.
- **[#10318](https://github.com/openshift/hypershift/pull/10318)** (CNTRLPLANE-4738): If generation of a replacement ignition payload fails, deleting its predecessor first can strand booting nodes; keep it until the replacement is published.
- **[release#89277](https://github.com/openshift/release/pull/89277)** (CNTRLPLANE-5029): The review found that an unexpectedly empty resource-group inventory can make the DNS cleanup select every CI-looking record; requested a guard and live delete-permission verification.
