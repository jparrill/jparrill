### Key Findings
- **[#8618](https://github.com/openshift/hypershift/pull/8618)** (OCPBUGS-86668): Empty bundle guard missing — if all certs expire, KAS rejects all client cert auth. Also found pre-existing bug: `hasKeys` at `support/certs/tls.go:452` checks `CASignerKeyMapKey` twice (typo), never checks cert key.
- **[#8946](https://github.com/openshift/hypershift/pull/8946)** (ARO-24037): Blocking — no convergence mechanism; nodepool controller has no watch on cloud config ConfigMaps, so after CPO updates the CM the nodepool controller never re-reconciles and ignition server retries indefinitely.
- **[OCPBUGS-95060](https://redhat.atlassian.net/browse/OCPBUGS-95060)**: Root cause — HC controller's `GetControlPlaneOperatorImageLabels` calls `quay.io` directly; in disconnected env DNS fails, blocking the entire reconcile loop and preventing `reconcileAdditionalTrustBundle` from ever running. 66k VMs impacted.
- **[CNTRLPLANE-3793](https://redhat.atlassian.net/browse/CNTRLPLANE-3793)**: Root cause of AWS resource leaks — `hypershift destroy cluster aws` hangs on stuck finalizers, script exits early, never cleans VPCs. Implemented force-cleanup with finalizer stripping + AWS API fallback. 9 resource types with finalizers audited.
- **[SUPPORTEX-32100](https://redhat.atlassian.net/browse/SUPPORTEX-32100)**: 4th support exception in 3 months for EgressIP on HCP (MAPFRE, UniCredit, Covea, FOD Financien — $5.4M ARR). All regulated industries in VMware→OpenShift migration wave. Same technical analysis as SUPPORTEX-31973 applies.
- **[#8871](https://github.com/openshift/hypershift/pull/8871)** (CNTRLPLANE-3615): Day-0 behavior change — even with no TLS profile set, Intermediate defaults will trigger one-time etcd StatefulSet rolling restart on CPO upgrade.
- **[OCPBUGS-98323](https://redhat.atlassian.net/browse/OCPBUGS-98323)**: Proxy conformance at 0% since Jan 2026 — root cause: `hypershift-aws` Boskos leases return UUIDs instead of region names, breaking CloudFormation calls in `blackholenetwork` step. Fix: add `AWS_REGION_OVERWRITE` support ([release#81729](https://github.com/openshift/release/pull/81729)).
