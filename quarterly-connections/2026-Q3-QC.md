## Q4 2026 — Top Priorities

**1. Deterministic LB IP (OCPSTRAT-2653)** — Drive the implementation of deterministic load balancer IP assignment for HCP. Enhancement proposal already authored (782 lines), API fields and feature gate PRs in progress. This is a strategic feature for customers requiring stable, predictable networking endpoints. https://redhat.atlassian.net/browse/OCPSTRAT-2653

**2. Backup/Restore evolution** — Multiple workstreams converging this quarter:
- Phase 2 implementation of the HCPEtcdBackup redesign (CNTRLPLANE-2678, enhancements#1945): move the controller from HO to CPO, run backup Jobs in the HCP namespace, introduce the cloudIdentity union for per-cloud workload identity (AWS IRSA, Azure MI, GCP SA), produce a complete restorable tarball artifact (etcd snapshot + PKI + CAPI objects), and remove cross-namespace access and fleet-wide shared credentials.
- CAPA and CAPZ changes for node readoption, enabling backup/restore flows for ROSA and ARO.
- Supporting the ROSA team's migration path from CSI snapshots to etcd snapshots — they will eventually migrate and we need to be ready to assist.
- Continue hardening the OADP plugin and DR procedures based on last quarter's work.

**3. OCPSTRAT-2666 (TBD)** — This feature is currently at risk due to limited time in the quarter. There are open questions about whether we will be able to commit to it. Will reassess based on bandwidth after Deterministic LB IP and B/R priorities stabilize. https://redhat.atlassian.net/browse/OCPSTRAT-2666

**4. Maintain delivery and review rate** — Sustain the closing-loop throughput from Q3: keep the verification, review, and cross-team support cadence that lets the whole team ship with confidence.

**5. CI reliability** — Continue iterating on CI health: monitoring, tooling improvements, and proactive flake elimination to protect the merge signal.
